Installation Guide

1. Download the ROM zip file.
2. Boot into TWRP Recovery.
3. Go to Wipe.
4. Wipe:
  • System
  • Data
  • Cache
  • Dalvik / ART Cache
5. Return to main menu.
6. Press Install.
7. Select the ROM zip file.
8. Swipe to flash.
9. Reboot system.
